# 📊 Student Marks & Grading System

A simple yet effective Python command-line application designed to collect student details, process subject marks out of 500, calculate pass/fail status, assign letter grades, and determine the top-ranking student in a class.

---

## 🚀 Features

* **Dynamic Inputs:** Takes student names and individual marks for 5 core subjects (Telugu, Hindi, English, Maths, Science).
* **Automated Total Calculation:** Computes total scores out of 500 for multiple students simultaneously.
* **Pass/Fail Validation:** Automatically evaluates if a student meets the minimum passing threshold (≥ 35 marks in all subjects).
* **Rank Determination:** Compares overall totals to highlight the First Rank holder.
* **Clean & Readable CLI Output:** Formats the final results nicely into a structured report card.

---

## 🛠️ Technologies Used

* **Language:** Python 3.x
* **Concepts Used:** Variables, Conditional Statements (`if-elif-else`), Logical Operators (`and`), Input/Output Handling.
